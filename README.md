# Raghav Reserve: Project Website

**Live:** https://raghav-reserve.vercel.app

Marketing and launch site for **Raghav Reserve**, a set of 2 & 3 BHK residences in Chikhali, Pune, with more than 60,000 sq.ft. of amenities (MahaRERA PM1260002501876).

## Highlights

- Responsive single-page site built to turn visitors into enquiries
- Project overview, configurations, amenities and location sections
- SEO meta tags and a lightweight static build that loads quickly on mobile
- Deployed on Vercel

## Tech

HTML · CSS · JavaScript · Vercel

## Run locally

Open `index.html` in a browser, or serve it:

```bash
npx serve .
```
